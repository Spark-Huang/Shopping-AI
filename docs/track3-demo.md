# 赛道三现场演示主线

## 名称与一句话

贵客来——说清送谁、预算和口味，AI 帮你挑贵州好物。

## 目标用户与痛点

目标用户是来黔游客、异地贵州人和需要贵州伴手礼的送礼者。现有方式需要在多个平台反复搜索，难以同时判断地域真实性、口味、预算和文化含义。

## 三步演示

1. 输入“预算 100 元，给第一次来贵州的朋友配一份不太辣的伴手礼”。
2. Agent 从贵州目录检索并展示带图片、人民币参考价和产地故事的候选商品，继续追问可比较或调整。
3. 打开详情核对来源与购买提示，加入购物车并跳转商家平台完成最终核验。

## 现场兜底

- 网络或模型暂时不可用时，仍可进入“好物”浏览本地目录项、查看详情、筛选和加入购物车；目录数据由爬虫链路接入后自动填充。
- 不演示模型临时生成商品或评价；所有商品卡来自本地可审计目录。
