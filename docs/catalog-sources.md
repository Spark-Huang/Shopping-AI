# 贵客来商品目录来源与合规说明

更新日期：2026-08-29

## 数据口径

- `platform/data/products.csv` 收录 52 个真实存在的贵州商品品类，不把聚合搜索结果伪装成某个商家的在售 SKU。
- `price` 为人民币参考价，只用于预算筛选与演示；实时售价、库存、规格、生产者和用户评价以跳转后的商家页面为准。
- `url` 是京东对应关键词的搜索入口，另提供淘宝搜索入口。平台链接不代表官方背书或合作关系。
- 当前本地商品图为 AI 辅助制作的品类示意图，界面明确标注“不代表具体商家 SKU”。接入获得授权的商家图片后，可将 `imageType` 改为 `merchant-photo`。
- 应用不生成虚构商品，不生成或冒充真实用户评价。

- 贵州省市场监督管理局地理标志公告，包含凯里红酸汤、龙里刺梨干等产品：<https://amr.guizhou.gov.cn/xwzx/tzgg/202204/t20220420_73510840.html>

## 新增目录项检查

1. 确认品类与贵州产地或贵州传统技艺存在可公开核验的关系。
2. 描述只写可由来源支持的事实，不写疗效、销量冠军、纯手工等未经证明的宣传语。
3. 商家图片必须有授权或明确可再分发许可，并记录来源与许可。
4. 不抓取、复制或生成“用户评价”冒充真实消费者反馈。
5. 为食品保留配料、保质期、过敏原和生产者核对提示。
