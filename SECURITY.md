# Security Policy

## Supported Versions

Only the current `main` branch receives security fixes.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through the GitHub security advisory feature for this repository. Do not open a public issue for exploitable behavior.

Include reproduction steps, affected endpoints or components, relevant request samples with secrets removed, and your suggested mitigation. Reports are acknowledged as soon as maintainers are able.

## Scope

Examples of reports we welcome include authentication bypass, unsafe request handling, prompt-driven data leakage, unsafe redirect or content handling, injection, and serious availability defects in the default deployment.

Out of scope examples include volumetric denial-of-service, unsupported deployment modifications, theoretical issues without reproduction, and automated scanner output without validation.
